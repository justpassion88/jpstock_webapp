📘 Hướng dẫn đọc bảng

P/B (Price-to-Book): Tỷ lệ giá/giá trị sổ sách. P/B thấp = rẻ, P/B cao = đắt.

P/B TB: P/B trung bình lịch sử ± độ lệch chuẩn (13 năm).

Percentile: Vị trí P/B hiện tại so với lịch sử (P10 = rẻ hơn 90% thời điểm).

Lợi Nhuận KV: Expected Return nếu P/B quay về trung bình × xác suất.

Định giá:

  • 🟢 Cực rẻ/Rẻ: P/B < percentile 25 → Nên mua
  • ⚪ Hợp lý: P/B trong vùng 25-75 → Giữ
  • 🔴 Đắt/Cực đắt: P/B > percentile 75 → Nên bán
